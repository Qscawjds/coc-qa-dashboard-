# CoC QA Dashboard — FTET Analytics

ระบบวิเคราะห์ภาระงานอาจารย์และข้อมูลประกันคุณภาพการศึกษา (FTET Analytics & Quality Assurance)  
**วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยสงขลานครินทร์ (College of Computing, Prince of Songkla University)**

เว็บแอปพลิเคชัน Dashboard แบบ Interactive สำหรับวิเคราะห์ข้อมูลค่า **FTET (Full Time Equivalent Teacher)** อิงข้อมูลจริงตามปีการศึกษา พ.ศ. 2562 – 2567 พร้อมเครื่องมือจำลองสูตรคำนวณภาระงานและระบบส่งออกรายงานหลากหลายรูปแบบ (PDF, Word, Excel)

---

## 🚀 ฟังก์ชันหลักของระบบ (Features)

1. **📈 ภาพรวมและแนวโน้ม (Overview & Trends)**
   - เปรียบเทียบแนวโน้มค่า FTET เฉลี่ยรายปีและรายภาคการศึกษา (เทอม 1 / เทอม 2)
   - กราฟแท่งเปรียบเทียบ FTET แยกตามแต่ละหลักสูตร (Comp, DE, DBiz, AISE, MsComp)
   - สรุปตัวชี้วัดสำคัญ (FTET เฉลี่ย, จำนวนอาจารย์, หลักสูตรภาระงานสูงสุด)

2. **👥 วิเคราะห์ภาระงานอาจารย์ (Teacher Workload Analysis)**
   - ตรวจสอบภาระงานอาจารย์รายบุคคล (36 ท่าน) ภาคเรียน 2567/2 ตรงตามข้อมูลจริง
   - ระบบค้นหาชื่ออาจารย์ (Search) และตัวกรองจำแนกตามหลักสูตร
   - แถบแสดงสถานะภาระงาน (ภาระงานเบา, ปกติ, สูง, เกินเกณฑ์มาตรฐาน)

3. **📊 สัดส่วนประเภทชั่วโมงสอน (Teaching Hours Breakdown)**
   - วิเคราะห์โครงสร้างชั่วโมงสอนรวมแบ่งตามประเภท: บรรยาย (Lecture ×2.0), ปฏิบัติการ (Lab ×1.5), และโครงงาน (Project ×1.0)
   - แสดงสัดส่วนเปอร์เซ็นต์ด้วย Doughnut Chart และจำนวนชั่วโมงสอนจริง

4. **🧮 เครื่องมือจำลองสูตร FTET (FTET Formula Simulator)**
   - กำหนดและทดลองปรับตัวแปรของรายวิชาได้อย่างอิสระ (ชม.บรรยาย, ปฏิบัติ, โครงงาน, กลุ่มเรียน, จำนวนสัปดาห์)
   - รองรับทั้งการเลื่อน Slider และการพิมพ์ตัวเลขลงในช่อง Input โดยตรง
   - ระบบ **Adaptive Limit Expansion**: เมื่อพิมพ์ตัวเลขเกินขอบเขตเดิม ระบบจะขยายสเกลและมาตรวัด (Gauge) ให้อัตโนมัติ พร้อมแจ้งเตือนเกณฑ์ภาระงานตามมาตรฐาน QA
   - เทมเพลตรายวิชาสำเร็จรูปสำหรับโหลดค่าเริ่มต้นอย่างรวดเร็ว

5. **🎨 Modern Corporate UI & Dark Mode**
   - ออกแบบสไตล์ Modern สะอาดตา เข้าใจง่าย พร้อมรองรับ Dark Mode ที่ปรับค่าความคมชัดของข้อความและเมนู Dropdown สวยงามกลมกลืน
   - โลโก้ทางการของมหาวิทยาลัยสงขลานครินทร์ (PSU) ปรับเฉดสีตามโหมดการแสดงผล

6. **📥 ระบบส่งออกรายงานประกันคุณภาพ (Export Report)**
   - **PDF (.pdf):** สร้างและดาวน์โหลดไฟล์ PDF ขนาด A4 พร้อมโลโก้ PSU, ตารางสรุป KPI, ตารางรายชื่ออาจารย์ และช่องลงนามรับรอง
   - **Word (.doc):** ส่งออกเอกสาร Microsoft Word จัดรูปแบบตารางสวยงาม พร้อมนำไปตัดต่อใส่ในเล่ม มคอ. หรือรายงาน QA
   - **Excel / CSV (.csv):** ดาวน์โหลดตารางข้อมูลพร้อม UTF-8 BOM สำหรับเปิดใน Excel ภาษาไทยได้ทันทีไม่เพี้ยน
   - **คัดลอกข้อความสรุป:** สรุปตัวเลขสถิติอย่างย่อพร้อมวางในอีเมลหรือแชต

## 💻 วิธีการรันบนเครื่อง Local

เนื่องจากระบบถูกพัฒนาเป็น **Pure Client-Side Web Application** ทำให้สามารถรันได้ทันทีโดยไม่ต้องติดตั้ง Backend เพิ่มเติม:

### วิธีที่ 1: ดับเบิลคลิกเปิดตรง
เข้าไปที่โฟลเดอร์โปรเจกต์แล้ว **ดับเบิลคลิกที่ไฟล์ `index.html`** เพื่อเปิดผ่านเว็บเบราว์เซอร์ได้ทันที

### วิธีที่ 2: รันผ่าน Local HTTP Server (แนะนำ)
เปิด Terminal หรือ PowerShell แล้วรันคำสั่ง:
```bash
python -m http.server 8502
```
จากนั้นเข้าใช้งานได้ที่: **[http://localhost:8502/index.html](http://localhost:8502/index.html)**

## ☁️ วิธีการ Deploy บน Vercel

โปรเจกต์นี้มีไฟล์ `index.html` และโฟลเดอร์ `assets/` อยู่ที่ Root directory จึงสามารถ Deploy บน **Vercel** ได้โดยตรงแบบ Zero Configuration:

1. นำโค้ดขึ้น **GitHub Repository**
2. เข้าสู่ [Vercel Dashboard](https://vercel.com) แล้วกด **Add New Project** -> เลือก Repository นี้
3. ในส่วน **Build and Output Settings**:
   - **Framework Preset:** เลือก `Other`
   - **Root Directory:** `./`
   - **Build Command:** **เว้นว่างไว้** *(ไม่ต้องใส่คำสั่ง build หรือ py)*
   - **Output Directory:** **เว้นว่างไว้** *(หรือระบุ `.`)*
   - **Install Command:** **เว้นว่างไว้**
4. กดปุ่ม **Deploy** ระบบจะปล่อยเว็บไซต์ขึ้น CDN ทันที รวดเร็ว เสถียร และไม่มีปัญหา Timeout

## 📐 สูตรการคำนวณค่า FTET

การคำนวณภาระงานเป็นไปตามเกณฑ์มาตรฐานประกันคุณภาพการศึกษา:

$$\text{FTET} = \frac{((\text{บรรยาย} \times 2.0) + (\text{ปฏิบัติการ} \times 1.5) + (\text{โครงงาน} \times 1.0)) \times \text{กลุ่มเรียน} \times \text{สัปดาห์}}{525}$$

- **1.0 FTET** คิดเทียบเท่าภาระงานสอน **525 ชั่วโมงต่อภาคการศึกษา** (หรือเฉลี่ย 35 ชั่วโมงต่อสัปดาห์ในภาคการศึกษาปกติ 15 สัปดาห์)
- เกณฑ์เป้าหมายมาตรฐานวิทยาลัย: **0.35 – 0.55 FTET** ต่อภาคการศึกษา
